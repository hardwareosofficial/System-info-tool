System Info Tool - Windows Release
=====================================

## Files
- SystemInfoTool.exe - Main executable
- portable.flag - Enable portable mode (no installation required)

## Installation

### Standard Installation
1. Run SystemInfoTool.exe
2. The app will install to your user directory and store settings in %APPDATA%

### Portable Mode
1. Keep both SystemInfoTool.exe and portable.flag in the same folder
2. Run SystemInfoTool.exe
3. Settings and data will be stored in a 'data' folder next to the executable
4. No installation required - runs entirely from this folder

## Requirements
- Windows 8/8.1/10/11 (64-bit)
- No additional dependencies required

## Features
- Comprehensive hardware detection (CPU, GPU, RAM, Storage, etc.)
- Cross-platform architecture (this build is Windows-specific)
- Modern dark-themed UI
- Export to HTML reports
- Email sharing capability
- Portable mode support

## Uninstallation
For standard installation, use Windows Apps & Features.
For portable mode, simply delete the folder.
